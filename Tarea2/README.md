# Tarea 2 - Estructuras de Datos y Algoritmos

Proyecto correspondiente al Laboratorio de la asignatura **Estructuras de Datos y Algoritmos**

## Descripción

Implementación de un reproductor de música mediante un menú interactivo en Java, utilizando estructuras de datos lineales para administrar canciones, listas de reproducción e historial de reproducciones.

## Funcionalidades

* Agregar, eliminar y buscar canciones.
* Reproducir canciones y almacenar el historial de reproducción.
* Consultar las últimas canciones reproducidas.
* Obtener estadísticas de reproducción y duración total.
* Crear y eliminar listas de reproducción.
* Agregar canciones y reproducir listas de reproducción.

## Estructuras de datos utilizadas

* **LinkedList:** gestión de canciones y listas de reproducción.
* **Stack:** almacenamiento del historial de reproducciones.
* **Queue:** administración de las listas de reproducción.

## Tecnologías

* Java
* Tipos de Datos Abstractos (TDA)
