# Tarea 3 - Estructuras de Datos y Algoritmos

Proyecto correspondiente al Laboratorio de la asignatura **Estructuras de Datos y Algoritmos**

## Descripción

Implementación de un buscador de música en Java que permite gestionar y buscar canciones utilizando distintas estructuras de datos y algoritmos de ordenamiento, evaluando su rendimiento mediante tiempos de ejecución.

## Funcionalidades

* Carga de canciones desde un archivo CSV.
* Ordenamiento por nombre y duración.
* Implementación de Bubble Sort, Insertion Sort, Merge Sort y Quick Sort.
* Medición de tiempos de ejecución mediante `System.nanoTime()`.
* Implementación de árboles binarios de búsqueda (BST).
* Búsqueda de canciones por nombre y duración.

## Estructuras de datos y algoritmos

* **ArrayList:** almacenamiento y gestión de canciones.
* **Árbol binario de búsqueda (BST):** búsqueda por nombre y duración.
* **Algoritmos de ordenamiento:** Bubble Sort, Insertion Sort, Merge Sort y Quick Sort.

## Tecnologías

* Java
* Archivos CSV
* Análisis de algoritmos y complejidad temporal
