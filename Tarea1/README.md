# Tarea 1 - Estructuras de Datos y Algoritmos

Informe correspondiente al Laboratorio de la asignatura **Estructuras de Datos y Algoritmos**

## Contenido

* **Pares entre dos filas:** implementación en Java para comparar dos filas de una matriz e identificar elementos pares coincidentes, indicando sus posiciones.
* **Análisis de complejidad Big O:** estudio de la complejidad temporal de algoritmos para invertir números y multiplicar matrices.

## Tecnologías

* Java
* Análisis de algoritmos y notación Big O
